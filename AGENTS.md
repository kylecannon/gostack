# gostack

gostack is a Go drop-in replacement for LocalStack Community. A user changes
`image: localstack/localstack` to `image: ghcr.io/kylecannon/gostack` and
nothing else. It also replaces gresau/localstack-persist, so persistence
follows that project's `PERSIST_*` contract.

## Parity

"Parity" means LocalStack's own pytest suite, run unchanged against a running
gostack container. gostack is at 100% when it passes every test that LocalStack
passes in the same runner. Tests LocalStack fails are recorded and not
required. `parity/ledger.json` holds the per-test result, and a regression is
never a deferral. The target is the LocalStack Community checkout at commit
`8b9a79f`. Pro-only services are out of scope. How the oracle works is in
`docs/architecture.md`.

## Commands

Run Go through `make`. The Makefile exports the `GOTOOLCHAIN` pin, and
golangci-lint 2.12 fails to type-check against the newer local toolchain.

```
make fmt     # golangci-lint fmt
make lint    # golangci-lint run
make test    # go test -race ./...
make build   # bin/gostack
```

Targets are added with the code that needs them.

## Where things are written down

- `docs/standards.md`: code, test and benchmark rules.
- `docs/architecture.md`: parity oracle, layout, HTTP stack, internal API,
  container and persistence contract, dependencies.

## Generated code

Everything under `internal/api/` is generated by `gostack-codegen` and starts
with `// Code generated by gostack-codegen. DO NOT EDIT.` Never edit it by
hand. Change the generator or the vendored specs in `specs/`, then regenerate.
