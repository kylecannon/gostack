# System benchmark 2026-11-18, 3971cef, full profile (clean tree)

Host: linux/aarch64, 10 CPUs, Docker 29.8.2, OrbStack true, kernel 7.2.12-orbstack-00394-gbecdd6130068, 24.5 GiB.

Every cell ran 3 times of 2 s, each time against a fresh container. Numbers are the median of the runs, with the range in the JSON. Memory is the resident set of the container (anon plus mapped file pages). CPU is a percentage of one core.

## Notes

- Host load before the run: load averages (1, 5, 15 min) 14.39 10.92 9.81 on 10 CPUs, from macOS daemons, not a quiet host. Both targets ran under the same load.
- Host load after the run (9:04): load averages (1, 5, 15 min) 18.29 15.11 14.11 on 10 CPUs.
- gostack S3 persistence is not wired (SQ-114), so there are no persist-on cells. LocalStack Community does not restore S3 under PERSISTENCE=1.
- listing cells: RSS and CPU include the seeding of 1k or 10k keys.

## Flags

Only three things are flagged. Everything else is in the tables above.

### A gostack cell ten times slower than LocalStack

A p50 ten times LocalStack's and over 1 ms, or a tenth of LocalStack's cycles a second. A persistence-on cell is held against LocalStack's persistence-off cell, which cannot persist.

none (or LocalStack was not measured)

### Memory that grows with object size

Peak RSS above the start of the run, held against the smallest payload of the same cell at the same concurrency: a rise of at least 16 MiB and half the bytes in flight. A cell with one payload size is flagged when it rises by the whole object.

- gostack `s3/objects/persist=off/payload=1MiB/c=16`: peak RSS 36.7 MiB, 23.7 MiB above the 1KiB cell (16.0 MiB in flight)
- gostack `s3/objects/persist=off/payload=64KiB/c=64`: peak RSS 37.8 MiB, 19.9 MiB above the 1KiB cell (4.0 MiB in flight)
- gostack `s3/objects/persist=off/payload=1MiB/c=64`: peak RSS 64.9 MiB, 46.8 MiB above the 1KiB cell (64.0 MiB in flight)
- gostack-slim `s3/objects/persist=off/payload=1MiB/c=16`: peak RSS 36.3 MiB, 23.4 MiB above the 1KiB cell (16.0 MiB in flight)
- gostack-slim `s3/objects/persist=off/payload=64KiB/c=64`: peak RSS 37.0 MiB, 19.3 MiB above the 1KiB cell (4.0 MiB in flight)
- gostack-slim `s3/objects/persist=off/payload=1MiB/c=64`: peak RSS 69.4 MiB, 51.5 MiB above the 1KiB cell (64.0 MiB in flight)
